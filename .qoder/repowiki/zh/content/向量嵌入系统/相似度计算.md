## 简介

本文档深入解析了基于 MongoDB 的知识库相似度计算系统，重点阐述余弦相似度算法的实现原理、数值稳定性、性能优化策略以及完整的相似度计算流水线。该系统支持多种知识类型（记忆、技能、规则、MCP、经验、命令、上下文、工作流），通过向量嵌入技术实现语义层面的知识检索和匹配。

## 余弦相似度算法实现

### 算法原理

余弦相似度是衡量两个非零向量之间角度的余弦值，用于评估向量方向的相似性，而不考虑其大小。

```mermaid
flowchart TD
Start([开始计算]) --> Validate["验证向量维度<br/>确保长度相同"]
Validate --> Valid{"维度有效？"}
Valid --> |否| Error["抛出错误"]
Valid --> |是| Init["初始化累加器<br/>dotProduct=0<br/>normA=0<br/>normB=0"]
Init --> Loop["遍历每个维度"]
Loop --> Calc["计算累加值<br/>dotProduct+=a[i]*b[i]<br/>normA+=a[i]*a[i]<br/>normB+=b[i]*b[i]"]
Calc --> Next{"还有元素？"}
Next --> |是| Loop
Next --> |否| Magnitude["计算范数<br/>magnitude=sqrt(normA)*sqrt(normB)"]
Magnitude --> Zero{"范数为0？"}
Zero --> |是| ReturnZero["返回0"]
Zero --> |否| Cosine["计算余弦相似度<br/>cosine=dotProduct/magnitude"]
Cosine --> End([结束])
ReturnZero --> End
Error --> End
```

- [src/services/embedding-service.ts](file://src/services/embedding-service.ts#L85-L104)

### 实现细节

余弦相似度计算的核心实现位于嵌入服务中，具有以下特点：

1. **输入验证**：确保两个向量具有相同的维度
2. **数值稳定性**：检查范数是否为零，避免除零错误
3. **高效计算**：单次遍历完成点积和范数计算
4. **标准化输出**：返回[-1, 1]范围内的相似度值

## 阈值设置与过滤机制

### 阈值配置

相似度阈值是控制搜索结果质量的关键参数：

| 阈值范围 | 适用场景 | 建议值 |
|---------|---------|--------|
| 0.0 - 0.3 | 严格匹配，高质量结果 | 0.7 - 0.9 |
| 0.3 - 0.6 | 中等宽松，平衡质量与数量 | 0.5 - 0.7 |
| 0.6 - 1.0 | 宽松匹配，扩大搜索范围 | 0.3 - 0.5 |

### 过滤机制

1. **阈值过滤**：只保留相似度高于阈值的结果
2. **类型过滤**：可按知识类型进行筛选
3. **数量限制**：限制返回结果数量
4. **排序过滤**：按相似度降序排列

## 精度控制与边界情况

### 精度控制

1. **相似度精度**：结果保留两位小数
2. **数值范围**：确保相似度值在[-1, 1]范围内
3. **浮点运算**：使用标准JavaScript浮点运算
4. **截断处理**：对长文本内容进行截断处理

### 边界情况处理

1. **空向量**：零向量与任何向量的相似度为0
2. **维度不匹配**：抛出明确的错误信息
3. **内存不足**：分批处理大型数据集
4. **网络异常**：重试机制和超时处理
5. **模型加载失败**：降级到基础处理模式

## 性能考虑与优化建议

### 性能基准

| 操作类型 | 处理时间 | 内存使用 | 适用场景 |
|---------|---------|---------|---------|
| 单文档嵌入 | 50-200ms | 50-100MB | 小规模处理 |
| 批量嵌入(100) | 5-10s | 200MB-500MB | 中等规模处理 |
| 批量嵌入(1000) | 50-100s | 2-5GB | 大规模处理 |
| 相似度计算(1000) | 1-5s | 100MB-200MB | 搜索操作 |

### 优化建议

1. **硬件优化**：使用SSD存储，增加内存容量
2. **算法优化**：考虑使用近似最近邻搜索算法
3. **缓存策略**：缓存常用查询结果
4. **索引优化**：在embedding字段上建立索引
5. **并发控制**：限制同时进行的相似度计算任务数量

## 故障排除指南

### 常见问题及解决方案

1. **模型加载失败**
   - 检查网络连接
   - 验证模型名称正确性
   - 检查磁盘空间

2. **相似度计算异常**
   - 验证向量维度一致性
   - 检查向量是否包含NaN值
   - 确认向量长度在合理范围内

3. **内存不足**
   - 减少批量处理大小
   - 增加系统内存
   - 优化数据预处理

4. **性能问题**
   - 检查数据库索引
   - 优化查询条件
   - 考虑分布式部署
